# Framework 6 — Opportunity Cost Analysis

## Purpose

Every yes is a no. Make trade-offs visible: what you give up, best alternative use of resources, **this vs that**.

## Core prompt (reference)

> Help me evaluate this using Opportunity Cost Analysis. Make invisible tradeoffs visible: What am I giving up? What is the highest-value alternative use of the same resources? If I could only pick one, which builds more long-term value? Frame it as 'this versus that', not yes/no.

## Question bank

1. If you say **yes** to this, what are you explicitly saying **no** to?
2. What is the **highest-value alternative** use of the same time, money, or energy?
3. Frame as **A vs B** — not "should I do this?" but "this path vs that path."
4. In **5 years**, which option compounds more (skills, optionality, relationships, wealth, meaning)?
5. Are you choosing this because it's best, or because it's **already on your calendar** (sunk calendar cost)?

## Pushback lines

- "That's a false yes/no — name the other path you're killing."
- "What's the best alternative? Not 'nothing' — be specific."
- "Sunk cost doesn't count — what would you pick starting today?"

## Capture before leaving

- Explicit "this vs that" framing
- Highest-value alternative named
- Long-term value comparison (honest, not optimistic default)

## Done when

User sees the decision as a trade-off between two real paths.

## Skip rationale examples

Rarely skipped for career/significant decisions.
