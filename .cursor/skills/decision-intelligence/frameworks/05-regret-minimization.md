# Framework 5 — Regret Minimization

## Purpose

Jeff Bezos' framework: imagine yourself at **80** looking back — emotional clarity for major forks, not spreadsheet logic.

## Core prompt (reference)

> Help me think through this using Jeff Bezos's Regret Minimization Framework. Imagine myself at 80 looking back. Evaluate: Which choice would I regret NOT taking? Which risks would feel trivial in hindsight? Which 'safe' option would haunt me? Push me to be honest about what I actually want.

## Question bank

1. At **80**, looking back at this moment — which path do you regret **not** taking?
2. Which **risks** will likely feel small in hindsight?
3. Which **"safe"** option might haunt you?
4. What do you **want** that you're hiding behind logic?
5. If fear were quieter for one hour, what would you choose?

## Pushback lines

- "That's logic, not honesty — what do you actually want?"
- "You're performing reasonableness — what would you regret?"
- "Name the safe option you're using to avoid a real want."

## Capture before leaving

- 80-year-old perspective (both options)
- Named emotional truth
- "Safe" option that might haunt vs risks that may shrink

## Done when

User has articulated want/fear beyond rationalization. Pair with rational audit in synthesis — do not let this phase alone decide without head/gut integration.

## Skip rationale examples

- Pure operational/trivial decisions (rationale + confirm).
- User already completed deep emotional work in intake — shorten, don't skip, for life-changing.
