# Framework 4 — Second-Order Thinking

## Purpose

Howard Marks' lens: map consequences in **three layers** for both doing and not doing the decision.

## Core prompt (reference)

> Help me think through this using Second-Order Thinking. Map consequences in three layers: → First order: What happens immediately? → Second order: What does that cause next? → Third order: What does THAT cause 6–12 months from now? Do this for both the 'I do it' and 'I don't do it' paths. Be brutally honest about downstream effects.

## Question bank

1. **Do it** — What happens in week 1? Month 1? Months 6–12?
2. **Don't do it** — Same three layers. What path are you defaulting into?
3. What **second-order effect** are you most underestimating?
4. Who else is affected in layer 2 or 3 (team, family, market)?
5. Which path has **more irreversible** third-order effects?

## Pushback lines

- "You're only thinking first order — what does that *cause* next?"
- "Be honest about the 6–12 month path you're not looking at."
- "Both paths — you only mapped one."

## Capture before leaving

- Table or bullets: 3 layers × (do / don't do)
- Highlighted underestimated effect
- Note on irreversibility

## Done when

Both paths have three layers with concrete outcomes, not platitudes.

## Skip rationale examples

Rarely skipped for significant/life-changing impact.
