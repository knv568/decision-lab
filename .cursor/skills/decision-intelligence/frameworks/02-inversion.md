# Framework 2 — Inversion

## Purpose

Charlie Munger's model: ask how to **guarantee failure**, then flip each item into an action to avoid.

## Core prompt (reference)

> I want you to help me solve a problem using Inversion. Instead of asking 'How do I succeed at this?', start by asking 'How would I guarantee failure at this?' List every way this could fail, every bad decision I could make, and every assumption that would destroy the outcome. Then flip each one into a concrete action I should take.

## Question bank

1. If you wanted to **guarantee failure** at this decision, what would you do? List at least five.
2. What **bad decisions** are you already tempted toward?
3. Which **assumptions**, if wrong, destroy the outcome?
4. What would make you look back in a year and say "I should have seen that coming"?
5. For each failure mode: what is the **one preventive action** you can take now?

## Pushback lines

- "That's generic — give me a scenario: what exactly fails, when?"
- "You're planning for success only. What's the fastest path to ruin?"
- "Flip that failure into a concrete 'do this / don't do this.'"

## Capture before leaving

- Failure modes (specific, not generic)
- Bad decisions to avoid
- Flipped preventive actions (paired list)

## Done when

At least 3 failure modes with matching preventive actions.

## Skip rationale examples

Rarely skipped — strong rational anchor for emotional decisions.
