# Seven frameworks — quick reference

| # | Framework | One line | Best for |
|---|-----------|----------|----------|
| 1 | **First Principles** | Break to fundamental truths; rebuild without convention | Rethinking stuck problems |
| 2 | **Inversion** | How to guarantee failure → flip to avoid | Durability, risk |
| 3 | **5 Whys** | Ask why until structural root cause | Recurring symptoms |
| 4 | **Second-Order** | 3 layers of consequences (do / don't) | Before committing |
| 5 | **Regret Minimization** | At 80, what would you regret not doing? | Big life/career forks |
| 6 | **Opportunity Cost** | Every yes is a no — compare alternatives | Commitments, time/money |
| 7 | **Pre-Mortem** | Assume failure; work backward; prevent now | Launches, big bets |

## Decision Lab session order

Intake → 1 → 2 → 3 → 4 → 5 → 6 → 7 → Synthesis (head / gut / integrated)

## Skip policy

All seven run by default. Skip only with **explicit rationale** + your confirmation. Record skips in the session file.

## Depth

Trivial → fewer questions; life-changing → more pushback and optional second rounds.
